# Comandos de VideoQA

Escríbelos en Claude Code, dentro de la carpeta del proyecto. También puedes pedirlo con tus
propias palabras: Claude entiende igual.

| Comando | Para qué sirve |
| --- | --- |
| `/instalar` | Deja todo configurado la primera vez: carpeta de videos, guía de marca y una prueba. |
| `/revisar` | Revisa los videos pendientes (o el que le digas) y te explica qué corregir y en qué segundo. |
| `/estado` | Te dice qué hay pendiente, cómo quedaron los últimos y si la revisión automática está encendida. |
| `/ajustar` | Añade palabras que no debe marcar como error y cambia qué problemas bloquean la publicación. |
| `/activar-automatico` | Enciende (o apaga) la revisión automática de todo lo que subas a `01_Entrada`. |

`revisor-video` no es un comando: es el criterio con el que Claude juzga cada video por dentro.
